# Launch checklist: [Product or feature name]

**Launch date:** [date] · **Owner:** [name]

## Before launch

**Product**
- [ ] PRD success metrics and guardrails agreed
- [ ] Acceptance criteria met for every Must requirement
- [ ] Empty, loading and error states reviewed
- [ ] Works on phone, tablet and desktop, including landscape and small screens
- [ ] Accessibility: keyboard navigation, focus states, reduced motion, screen-reader labels

**Quality**
- [ ] Automated tests pass
- [ ] For AI features: eval suite meets the bar to ship (see eval plan)
- [ ] Tested against production-like data and settings

**Security and privacy**
- [ ] No secrets in client code or the repo
- [ ] Personal data reviewed: only what's needed, and nothing users wouldn't expect
- [ ] Abuse limits: input size, rate limits, timeouts

**Operations**
- [ ] Production access settings checked (auth, protection, permissions)
- [ ] Deploy pipeline tested end to end
- [ ] Monitoring and alerts in place, and someone watching on launch day
- [ ] Rollback plan written and tested

**Go-to-market**
- [ ] Users can discover the feature
- [ ] Docs, FAQ or in-product help updated
- [ ] Stakeholders told what's launching and when

## After launch

- [ ] Day 1: error rates, usage, and any user reports reviewed
- [ ] Week 1: metrics compared to targets
- [ ] Launch notes written: what went well, what surprised us, what we'd change
